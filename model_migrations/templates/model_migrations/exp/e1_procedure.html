Follow these steps on your own computer, then use the Simulation page to experiment with model design interactively.

  1. Create a project and an app. 
    django-admin startproject mysite
cd mysite
python manage.py startapp library
  2. Register the app by adding it to INSTALLED_APPS in mysite/settings.py. Django only looks for models in registered apps. 
    INSTALLED_APPS = [
    # ... built-in apps ...
    "library",
]
  3. Define your models in library/models.py. 
    from django.db import models

class Author(models.Model):
    name = models.CharField(max_length=100)

    def __str__(self):
        return self.name


class Book(models.Model):
    title = models.CharField(max_length=100)
    pages = models.IntegerField()
    author = models.ForeignKey(Author, on_delete=models.CASCADE)

    def __str__(self):
        return self.title
  4. Check for mistakes. 
    python manage.py check
    You should see System check identified no issues (0 silenced).
  5. Predict the table. Before moving on, write down the table names, the column names and the type of each column. Then compare your answer with the Model Builder on the Simulation page.
  6. Continue to Experiment 2 to turn these models into real database tables with migrations.
