Continue with the library app from Experiment 1. Run each command from the folder that contains manage.py.

  1. Create the first migration. 
    python manage.py makemigrations library
    Expected output (the exact lines depend on your models): 
    Migrations for 'library':
  library/migrations/0001_initial.py
    + Create model Book
    Open library/migrations/0001_initial.py and read it.
  2. See which migrations are applied. 
    python manage.py showmigrations library
    0001_initial is shown as [ ]: it exists as a file but the database does not have it yet.
  3. Preview the SQL. 
    python manage.py sqlmigrate library 0001
    You will see a CREATE TABLE "library_book" ... statement. Nothing has run yet.
  4. Apply the migration. 
    python manage.py migrate library
    Running migrations:
  Applying library.0001_initial... OK
  5. Confirm. Run showmigrations again. It now shows [X] 0001_initial. You can also open db.sqlite3 in a SQLite viewer and look at the library_book and django_migrations tables.
  6. Run makemigrations again without changing the models. Django reports No changes detected in app 'library'.
  7. Use the Simulation. Step through the whole lifecycle, including a second migration that adds a field, and watch each of the four panels change.
