Objective

After completing this lab, the student will be able to:

  • Explain how Django's ORM maps a model class to a database table and its fields to columns.
  • Define models using common field types and options such as null, blank, default and unique.
  • Relate models to each other using ForeignKey and choose a suitable on_delete behaviour.
  • Generate migration files with makemigrations and apply them with migrate.
  • Inspect migrations using showmigrations and sqlmigrate, and read the django_migrations table.
  • Evolve an existing schema by adding, removing, renaming and altering fields.
  • Roll the database back to an earlier migration and explain what data can be lost.
