Start from the library app with 0001_initial applied and a few rows saved in Book.

  1. Add a nullable field. In models.py add 
    published = models.DateField(null=True)
    Run python manage.py makemigrations library. Django creates 0002_book_published.py containing an AddField. Run python manage.py migrate. Existing rows now have NULL in published.
  2. Add a required field. Add 
    rating = models.IntegerField()
    Run makemigrations. Django warns that it cannot add a non-nullable field without a default and offers a one-off default. Choose option 1 and enter 0. Apply with migrate.
  3. Rename a field. Change pages to page_count in the model. When Django asks whether the field was renamed, answer y. Check that the generated file contains a RenameField.
  4. Alter a field. Change max_length=100 to max_length=200 on title. You will get an AlterField.
  5. Roll back. Go back to the first migration: 
    python manage.py migrate library 0001
python manage.py showmigrations library
    The later migrations show as [ ] again, even though their files (and your models) are unchanged.
  6. Roll forward. Run python manage.py migrate library to apply them again.
  7. Use the Simulation to repeat all of this on a live table and to watch what happens to the data, including what a rollback cannot bring back.
