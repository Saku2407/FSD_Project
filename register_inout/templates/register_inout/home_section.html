{% if active == "objectives" %}

After completing this Virtual Lab, a student should be able to:

  • Explain authentication and authorization.
  • Use Django's built-in User model.
  • Build and validate a registration form.
  • Understand password hashing and password validation.
  • Authenticate users with authenticate().
  • Create and end sessions using login() and logout().
  • Use request.user and @login_required.
  • Understand CSRF protection for POST forms.
  • Store quiz attempts and feedback in SQLite.
  • Inspect application data through Django Admin.
