Analysis

  1. The browser sends a request to a Django URL.
  2. Django URLconf selects the corresponding view.
  3. The view reads request data and invokes the appropriate form/authentication/database operation.
  4. Django validates the input.
  5. The view either displays errors, stores data, logs a user in/out, or redirects.
  6. For authenticated requests, Django makes the current user available as request.user.
