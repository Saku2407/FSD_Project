01 / EXPERIMENT OBJECTIVE

Aim

Learn version control by managing a simulated Git repository for a small Django project.

Estimated Time

60 minutes

Learning Objectives of the Experiment

After completing the experiment “Git Repository Management for a Django Project”, students will be able to:

  • Explain repositories, the working directory, staging area (index), commits and HEAD.
  • Initialize a local repository with git init and inspect git status.
  • Stage selected Django project files using git add and create commits with git commit.
  • Understand file changes that occur after staging.
  • Create a feature branch, switch between branches and inspect git log.
  • Perform a fast-forward merge and distinguish it from a merge requiring conflict handling.
  • Apply Git commands to a real Django project after completing the safe simulation.
Aim

To simulate Git repository management operations on a Django project and observe how file changes move from the working directory into the staging area and version history.
