Try the real Git commands locally

After creating a Django project folder, open a terminal inside it and try the following. Add a suitable .gitignore first to exclude .venv/, db.sqlite3 and secrets.

POWERSHELL / TERMINAL
git init
git status
git add .
git commit -m "Initial Django project"
git branch feature
git switch feature
# Make a code change, then:
git add .
git commit -m "Add a new view"
git switch main
git merge feature
git log --oneline

If your local Git uses a different initial branch name, run git branch -M main after the first commit.
