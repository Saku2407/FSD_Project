03 / LAB PROCEDURE

Procedure

Complete a miniature Django repository workflow. Every action updates a practice model in your browser session.

01

Initialize the repository

Open the Simulation and click git init.

02

Stage initial Django project files

Use git add to stage README.md, manage.py, and requirements.txt.

03

Create the first commit

Enter Initial Django project and click git commit. Inspect the commit list.

04

Create and switch to a feature branch

Run git branch feature followed by git switch feature.

05

Edit, stage and commit a Django file

Choose lab/views.py, enter a sample view, save, stage it and commit with the message Add home view.

06

Merge into main

Switch to main while the working tree is clean. Run git merge feature to observe the fast-forward.

07

Review results

Inspect status, the branches panel, commit history, Observations and the Posttest.

Expected Result

The repository is initialized, the first snapshot is committed on main, a new commit is created on feature, and main is advanced to the feature tip by a fast-forward merge. The working tree should be clean.
