Template Filters

Filters change the representation of context values when a template displays them.

Commonly used filters

FilterExamplePurpose
uppername|upperDisplay uppercase text
lowername|lowerDisplay lowercase text
titlename|titleCapitalize each word
lengthskills|lengthCount items in a list or characters in text
defaultnickname|default:"Guest"Display a fallback for a false or missing value

Template code

{% verbatim %}
<p>{{ result.name|upper }}</p>
<p>{{ result.name|title }}</p>
<p>Skills: {{ result.skills|length }}</p>
{% endverbatim %}

The Simulation uses upper, title, first and length to render formatted values.
