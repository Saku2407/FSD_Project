Step 1: Query the model in a view

models_data() · views.py (simplified)
records = StudentRecord.objects.order_by('-created_at')[:8]
context = {'records': records}
return render(request, 'views_template/models_data.html', context)

The actual project filters records to the current browser session, so each student sees only their own demonstration entries.
