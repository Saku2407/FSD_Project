04 / LAB PROCEDURE

Perform the experiment

Follow the procedure below to see how values entered by a user travel through a Django view to an HTML template.

01

Open the simulation

Navigate to the Simulation section from the sidebar.

02

Enter student information

Provide a name, select a course, choose marks from 0–100, and enter a few skills separated by commas.

03

Click “Run experiment”

The browser submits an HTTP POST request to the Django simulation() view. Django validates the submitted form.

04

Inspect the context and rendered output

The view constructs a Python dictionary and passes it to render(). Observe how the template displays variables, loops through skills and applies conditional logic.

05

Try different values

Change the marks to less than 40 and run it again. Observe how the displayed status changes from PASS to FAIL.

06

Record observations and take the posttest

Review your recent simulation runs in Observations, then answer the posttest MCQs.

Expected result

On successful execution, your submitted student data will appear on the result card. A list of skills will be rendered using a for tag, and the pass/fail status will be displayed based on marks.
