What is a Django View?

A Django view is Python code that receives a request and returns an HTTP response. It prepares the context data that an HTML template will display.

Simple example

views.py
from django.shortcuts import render

def student_view(request):
    context = {
        "name": "Yash Kapadiya",
        "course": "Django",
        "marks": 82,
    }
    return render(request, "student.html", context)

The dictionary keys name, course, and marks become available to student.html.

Connect the URL to the view

urls.py
from django.urls import path
from . import views

urlpatterns = [
    path("student/", views.student_view, name="student"),
]

Visiting /student/ calls student_view(), which sends the template-rendered response to the browser.
