Template Tags

Template tags control how HTML is produced. The most common tags for this experiment are if and for.

Conditional display: if

Show a message according to the value of marks passed by the view.

{% verbatim %}
{% if result.marks >= 40 %}
  <p>PASS</p>
{% else %}
  <p>FAIL</p>
{% endif %}
{% endverbatim %}

Displaying a list: for

Each skill in the context list becomes an HTML list item.

{% verbatim %}
<ul>
{% for skill in result.skills %}
  <li>{{ skill }}</li>
{% endfor %}
</ul>
{% endverbatim %}
