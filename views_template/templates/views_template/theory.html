How data reaches a template

Django separates Python processing from HTML presentation. A view prepares the data, and a template displays it.

What is a Django view?

A view is a Python function (or class) that handles an HTTP request and returns an HTTP response. It can prepare values, read form input, fetch records and choose which template to render.

1. Create data in views.py

The view builds a dictionary. Every dictionary key becomes a variable name available inside the template.

PYTHON · views_template/views.py
from django.shortcuts import render

def example(request):
    context = {
        "student_name": "Yash Kapadiya",
        "marks": 82,
        "skills": ["Python", "HTML", "Django"],
        "student": {"city": "Hyderabad"}
    }
    return render(request, "example.html", context)

render(request, template_name, context) combines the HTML template with the context data and returns an HTTP response.

2. Access data in the template

HTML · example.html
{% verbatim %}
<h1>Hello {{ student_name }}!</h1>
<p>Marks: {{ marks }}</p>
<p>City: {{ student.city }}</p>
<ul>
  {% for skill in skills %}
    <li>{{ skill }}</li>
  {% endfor %}
</ul>
{% endverbatim %}

Use double curly braces to output a variable, dot notation for dictionary keys, and template tags for logic such as looping through a list.

Conditional rendering

Choose which HTML to display based on a value:

{% verbatim %}
{% if marks >= 40 %}
  PASS
{% else %}
  FAIL
{% endif %}
{% endverbatim %}

Template filters

Format values without modifying the Python data:

{% verbatim %}
{{ student_name|upper }}
{{ skills|length }}
{{ student_name|title }}
{% endverbatim %}
Key concept

For this experiment, the browser submits data, Django validates it, constructs a context dictionary in the view, and finally renders the page using the values in that context.
