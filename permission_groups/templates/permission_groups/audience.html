Target Audience

This lab is intended for:

  • Undergraduate students of Computer Science, Information Technology and related branches studying web development.
  • Postgraduate students working on web application projects that need role-based access control.
  • Self-learners and developers who already know basic Django (models, views, templates) and want to learn authorization.
  • Teachers who need a structured set of activities for a web frameworks course.

Prerequisites: basic Python, and familiarity with Django models, views, URLs and templates.
