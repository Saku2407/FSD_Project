Objective

After completing this lab, the student will be able to:

  • Explain the difference between authentication and authorization in Django.
  • Describe the User, Permission and Group models and how they relate to each other.
  • Use the default add, change, delete and view permissions created for every model.
  • Define custom permissions in a model's Meta class.
  • Create groups and assign permissions and users to them from the admin site and the Django shell.
  • Restrict access to views using @permission_required, PermissionRequiredMixin and user.has_perm().
  • Control what is displayed in templates using the perms variable.
