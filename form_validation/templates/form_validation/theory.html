Theory

Step 1: Define the form

Create a form class and declare its fields. Built-in validation already covers types and required fields.

from django import forms
from django.core.exceptions import ValidationError


class RegistrationForm(forms.Form):
    username = forms.CharField()
    email = forms.EmailField()
    age = forms.IntegerField()
    password = forms.CharField(widget=forms.PasswordInput)
    confirm_password = forms.CharField(widget=forms.PasswordInput)

Step 2: Field-level validation with clean_<fieldname>()

Name the method clean_ followed by the field name. Django calls it automatically. Read the value from self.cleaned_data, raise ValidationError if it is bad, and always return the value. 

def clean_username(self):
    username = self.cleaned_data["username"].strip()

    if len(username) < 4:
        raise ValidationError(
            "Username must have at least 4 characters.",
            code="username_too_short",
        )

    if not username.replace("_", "").isalnum():
        raise ValidationError(
            "Only letters, digits and underscores are allowed.",
            code="username_invalid_chars",
        )

    return username


def clean_age(self):
    age = self.cleaned_data["age"]

    if age < 18:
        raise ValidationError(
            "You must be at least 18 years old to register.",
            code="age_too_young",
        )

    return age
Common mistake: forgetting return username. The field then becomes None in cleaned_data.

Step 3: Cross-field validation with clean()

clean() runs after every field-level method. Call super().clean() first, then compare fields. Fields that already failed are missing from cleaned_data, so use .get() instead of square brackets. 

def clean(self):
    cleaned_data = super().clean()

    password = cleaned_data.get("password")
    confirm_password = cleaned_data.get("confirm_password")

    if password and confirm_password and password != confirm_password:
        # Attach the error to one specific field
        self.add_error(
            "confirm_password",
            ValidationError("The two passwords do not match.", code="password_mismatch"),
        )

    return cleaned_data

To create a non-field error (shown at the top of the form), pass None as the field name: 

self.add_error(
    None,
    ValidationError("The password must not contain your username."),
)
